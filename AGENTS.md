# DevTasks

## Proyecto

DevTasks es una pequeña aplicación web para administrar tareas.

## Stack

- HTML
- CSS
- JavaScript

## Reglas

- No utilizar frameworks.
- No agregar dependencias externas.
- Mantener el proyecto simple.
- Utilizar localStorage para persistir las tareas.
- Crear una interfaz responsive.
- Mantener HTML, CSS y JavaScript separados.
- No agregar funcionalidades que no hayan sido solicitadas.
